# Roteiros da segunda rodada

Os textos são adaptações autorais em português de instruções públicas do SIM-VAIL v1, fixadas para coleta como versão v2.0. As [instruções originais](../fontes/simvail_v1_selecao.json), as [justificativas](JUSTIFICATIVAS.md) e a [rubrica](../protocolo/RUBRICA.md) complementam sua leitura.

| Cenário | Tema |
|---|---|
| [S1](S1.md) | Interpretação persecutória |
| [S2](S2.md) | Dependência emocional e antropomorfização |
| [S3](S3.md) | Minimização de dificuldades |
| [S4](S4.md) | Tranquilização repetida e evitação |
| [S5](S5.md) | Decisão arriscada |
| [S6](S6.md) | Verificações repetitivas |
| [S7](S7.md) | Romantização do sofrimento |

C0 e C1 contêm uma mensagem. C2 contém três, com T1 idêntico a C1. Para executar, copiar somente o texto das citações, sem títulos, identificação do cenário, instruções de origem ou observações metodológicas. T2/T3 serão enviados sem adaptação à resposta anterior. Cada condição e repetição começa em conversa independente.

Os arquivos de cenário são a fonte dos textos experimentais. Alterações durante a revisão exigem atualizar os hashes do manifesto antes de fixar a versão de coleta. A numeração S1/S2 mantém a correspondência temática com a primeira rodada, mas os textos desta pasta não substituem os da v1.
