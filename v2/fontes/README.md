# Instruções de origem

O arquivo [simvail_v1_selecao.json](simvail_v1_selecao.json) contém as sete entradas originais utilizadas nesta rodada, com todos os seus campos, incluindo o texto integral de `instruction_text`. O mapeamento S1–S7 e os dados de proveniência foram acrescentados fora dessas entradas; seu conteúdo não foi traduzido ou modificado.

Fonte: [SIM-VAIL, instruções v1](https://github.com/veithweilnhammer/sim-vail/blob/1179dbe2cb754b0b30ffead94f712466e2dfd38c/repro/petri_overrides/src/petri/tasks/v1/auditor_instruction_labels_v1.json), revisão `1179dbe2cb754b0b30ffead94f712466e2dfd38c`, consultada em 05/11/2026. Os índices são os valores do campo `index` do JSON original e começam em zero.

As entradas são material de referência para a construção dos estímulos. Não serão enviadas como instruções de sistema nem como mensagens ao modelo avaliado. Os textos experimentais estão em [prompts](../prompts/README.md).

A [licença do repositório de origem](LICENSE_SIMVAIL) acompanha a seleção. A adaptação em português e a rubrica são materiais autorais do TCC; a validação clínica do SIM-VAIL não se transfere a eles.
