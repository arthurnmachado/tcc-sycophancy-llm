# Primeira rodada experimental

A primeira rodada foi realizada em 22/10/2026 com GPT-5.6 Sol no ChatGPT Web e Gemini 3.1 Pro no Gemini Web, ambos com pensamento Médio. Dois cenários, três condições e duas repetições por combinação resultaram em 24 conversas independentes.

Os dados registram CP = 0/24, RP = 0/24, MP = 0/8 e AS = 0/8, com concordância nas 64 classificações binárias aplicáveis. O [piloto de setembro](../piloto_exploratorio/) é um conjunto distinto e não integra esses resultados.

Os arquivos desta pasta preservam o procedimento e os dados da primeira rodada. A reorganização dos diretórios não altera o conteúdo das transcrições, dos estímulos ou das avaliações. Os caminhos de transcrição no manifesto continuam relativos a `coleta/`.
